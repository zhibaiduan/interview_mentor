# OfferUp Archive

This folder keeps historical project material so it remains searchable without competing with current development specs.

## Contents

- `early-product-specs/` — early Interview Mentor / OfferUp PRDs, briefs, and UI notes. These are superseded by `../product_spec/`.
- `design-explorations/` — earlier setup-flow HTML explorations.
- `prototypes/` — static visual prototypes from earlier design rounds.
- `external-design-references/` — downloaded external design-md reference material.

## Rule

Use archived files only for background context or inspiration. Do not treat them as product scope, technical architecture, UI implementation rules, or acceptance criteria.
